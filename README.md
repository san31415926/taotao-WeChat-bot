# 微信群发工具

自动控制微信 PC 版，实现批量群发消息到多个微信群。支持图形界面和命令行两种方式。

> **开发：** 淘淘数码  
> **声明：** 本软件仅限于授权用户内部使用，禁止用于任何商业用途。

---

## 功能

- **批量群发** — 自动搜索群名前缀，依次发送到多个群
- **图形界面** — 参数编辑、文件勾选、运行控制、发送统计一应俱全
- **定时模式** — 设定时间自动发送，无需值守
- **速度控制** — 可调倍率，从正常到极速自由切换
- **媒体群发** — 支持 TXT、JPG/PNG/GIF/WEBP 等图片，以及 MP4/MOV/AVI/MKV 等视频
- **紧急停止** — 鼠标移左上角或按停止按钮，立即中止
- **配置持久化** — 参数保存后下次启动自动加载

## 快速开始

```bash
# 安装依赖
pip install pyautogui pyperclip pygetwindow pywin32 schedule

# 图形界面（推荐）
python gui.py

# 或命令行
python send_wechat.py --once
```

也可直接运行打包好的 `微信群发工具-媒体版.exe`（无需 Python 环境）。

## 详细文档

GUI 优先扫描当前目录下的产品文件夹。每个文件夹必须包含一个非空 TXT 和一张图片或一个视频；文件名可任意。程序会将同一文件夹视为一个发送组合，固定先发 TXT、再发图片或视频，文件夹之间才使用“文件发送间隔”。

文件夹较多时，可在“选择发送组合”区域的搜索框输入名称关键词，列表会实时筛选；清空搜索框即可恢复完整列表，已勾选的文件夹会保留。

“视频转发完成后等待”可单独设置视频已发送到所有群后、处理下一组内容前的等待时长，支持 `30s`、`5m`、`1h` 等格式。

同一产品组合会按群名前缀完成发送：例如先完成 `00A001` 的文字和媒体，再处理 `00A002`，不会把所有文字集中发送后才发送媒体。

例如：

```text
苹果16PM黑色256G/
  新建 文本文档.txt
  o1785499683713_130_0_0.mp4
```

没有符合规则的产品文件夹时，程序仍会兼容读取根目录中的旧版 TXT、图片和视频文件。媒体会先发送到自己的微信，再沿用原有的转发流程发送到群。

媒体发送使用 Windows 文件剪贴板（`CF_HDROP`），不依赖固定的“添加文件”按钮坐标。视频较大时，可在 GUI 中适当增大“图片/视频上传等待秒数”。

视频消息右键后会按 3 次下箭头再回车选择“转发”；图片沿用文字消息的菜单路径。

## 文件结构

```
├── gui.py                 图形界面
├── send_wechat.py         核心自动化脚本
├── 使用说明.md            详细文档
├── *.txt / *.jpg / *.png   文本和图片发送文件
├── *.mp4 / *.mov / *.mkv   视频发送文件
├── 产品文件夹/              一个 TXT + 一张图片或一个视频，固定先文字后媒体
├── 微信群发工具-媒体版.exe  支持媒体的打包程序
├── data/
│   ├── config.json        持久化配置
│   └── send_stats.json    发送统计
└── dist/
    └── 微信群发工具.exe    打包可执行文件
```
